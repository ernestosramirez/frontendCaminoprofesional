# Camino Profesional — Frontend

Interfaz web de Camino Profesional, una plataforma orientada a guiar a futuros profesionales del sector tecnológico con información sobre grados, especializaciones, salidas laborales y salarios.

Enlace al Backend: [backendCaminoProfesional](https://github.com/ernestosramirez/backendCaminoProfesional)

---

Funcionalidades
- Guía IT: Información sobre titulaciones, especialidades y rangos salariales.
- Autenticación: Registro e inicio de sesión de usuarios.
- Panel Admin: Gestión y asignación de roles de administrador.
- Tienda: Catálogo de libros recomendados sobre informática.
- Consumo de API: Comunicación asíncrona con el backend vía `fetch`.

---

Tecnologías
- HTML5, CSS3, JavaScript, Angular y Git/GitHub.
